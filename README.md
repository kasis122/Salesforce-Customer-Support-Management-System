# Customer Support Management System

## Project Overview
A Salesforce-based Customer Support Management System designed to manage customer cases, automate case priorities, monitor SLAs and generate reports.

## Technologies Used
- Salesforce CRM
- Salesforce Workflow Rules
- Salesforce Validation Rules
- Salesforce Email Alerts
- Salesforce Reports and Dashboards

## Main Features
1. Case Management
2. Automatic Case Priority Assignment
3. Case Validation
4. Email Notifications
5. SLA Monitoring
6. Support Categories
7. AI Feedback Management
8. Reports and Dashboards
